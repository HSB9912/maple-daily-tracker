💰 부분정산 — 재화 지정 방식

현재는 부분정산하면 변동가 재화(다조 등)가 먼저 자동 차감돼서 기록이 꼬입니다. 이번에 준 재화를 직접 지정하는 방식으로 바꾸는 안입니다.

1 뭐가 문제인가

상황: 넘굴 누적 31억 7,600만 쌓인 상태에서 현금 30,000원(≈ 3억 1,578만 메소)만 부분정산으로 받음.
✗ 지금 (우선순위 자동 차감)
변동가 → 고정가 → 매소 순서라 다조가 먼저 소진됩니다.

실제로는 그냥 현금 3만원 받은 건데, 표에는 다조 26.3개가 정산 완료로 찍힙니다. 다조는 아직 손도 안 댔는데 26개가 사라져 보이니 나중에 대조가 안 맞음. 게다가 소수점(26.3개)까지 생깁니다.

5 구현 요약

추가/변경되는 것
  • 정산 모달에 🎯 재화 지정 탭 신설 (기존 현금/메소/선금/전체 탭은 그대로 유지)
  • entry에 type:'items' + allocations:{재화:수량} 필드 추가. mesoEquiv는 지정 수량 × 정산 시점 시세로 자동 계산 후 박제
  • allocatePaidToResources() 수정 — 지정 수량이 있는 entry는 그 재화에서 정확히 차감, 지정 없는 기존 entry만 종전대로 우선순위 차감
  • 수량 입력은 누적 잔여를 넘지 못하게 클램프 (초과 입력 시 자동으로 잔여까지만)
기존 데이터 호환
  • 이미 기록된 정산(allocations 없음)은 지금과 100% 동일하게 계산됩니다 — 과거 기록이 바뀌지 않음
  • 잠긴(🔒) 정산 스냅샷·전체정산·선금 로직은 손대지 않음
