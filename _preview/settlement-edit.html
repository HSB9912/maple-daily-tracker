4 구현 요약

추가되는 것
  • 정산 이력 각 줄(활성 + 🔒잠긴 것 모두)에 ✎ 수정 버튼
  • 수정 모달에서 날짜 · 방식 · 금액 · 메모 변경. 방식은 현금 ↔ 메소 ↔ 재화 지정 ↔ 선금 자유 전환
  • 재화 미지정 정산에는 소수점 경고 + "재화 지정으로 전환" 원클릭 버튼 — 원래 금액을 매소에 그대로 배정해 잔여가 안 흔들리게
  • 재화 지정 시 원래 금액과 차이가 나면 차액을 표시해서 실수로 잔여가 바뀌는 걸 막음 (의도한 거면 그대로 저장 가능)
지켜지는 것
  • 박제된 시세는 수정해도 유지 — 그때 시세로 계산된 값이 지금 시세로 바뀌지 않음
  • 🔒 잠긴 정산을 수정해서 금액이 크게 달라지면 자동 정리 상태를 다시 계산 (잠금이 안 맞으면 풀림)
